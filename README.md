# Student Support Request Tracker

A simple web page where a student can submit an academic or administrative support request and see whether it has been received or resolved.

*Local version:* requests are saved in the browser (localStorage) on one device only. There is no backend or database.

## Setup
1. Download or clone this repository.
2. Open index.html in a web browser. Nothing needs to be installed.

## Features
- Responsive layout for phones and computers, built with HTML, CSS and JavaScript
- Request form with three fields: name, request type (Academic or Administrative) and description
- Validation: the form cannot be submitted if any field is empty
- Requests are saved in the browser and shown on the page, and they stay after a refresh
- Each request has a status: Submitted, In Progress or Resolved
- A button moves a request to the next status, to demonstrate the workflow

## Limitations
- Data is stored only in this browser, so other people and other devices cannot see it
- Clearing the browser's site data deletes the requests
- No login: anyone using the browser can change a status
- No email notifications

## What I would improve
- Add a real backend and database so requests are shared
- Add separate student and staff logins, so only staff can change statuses
- Send an email when a status changes
- Add an email field with better validation
